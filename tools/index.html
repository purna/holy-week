HOLY WEEK

TOOLS
A collection of development tools for Holy Week. Each tool explores a different facet of game development: editor tools, dialogue systems, tilemap design, and story-telling engines. Built with Three.js, Cannon-es, Ink, and Howler.
Editor Tool

Earth Grid Editor

Flatten the planet into a 60×30 longitude/latitude grid. Hover to select cells, choose an object type, and click or double-click to place. Shows all 3D object positions on the 2D map. Export or import the full grid as JSON.
